# Anti-Slop & Conversion Copywriting Skill

Prevents AI coding assistants from writing robotic, cliché marketing filler text. Enforces clear, concise, outcome-driven copy grounded in Jobs-to-be-Done (JTBD).

---

## 1. Banned AI Vocabulary

NEVER generate or accept copy containing the following robotic AI filler words:

| Banned AI Word | What to Write Instead |
| :--- | :--- |
| **"Delve into"** | "Explore", "Inspect", "Review", "Step inside" |
| **"Unleash" / "Harness"** | "Use", "Enable", "Run", "Trigger" |
| **"Testament to"** | "Proof that", "Demonstrates", "Shows" |
| **"Tapestry" / "Plethora"** | "Collection", "Catalog", "Range", "Set" |
| **"Revolutionize" / "Game changer"** | "Cuts 4 hours a week", "Automates manual entry" |
| **"Supercharge" / "Turbocharge"** | "Speeds up", "Accelerates", "Replaces" |
| **"Beacon" / "Pinnacle"** | "Standard", "Example", "Model" |
| **"Cutting-edge" / "Next-gen"** | Specific specs (e.g. "Next.js 15 RSC", "4K 60fps") |

---

## 2. Jobs-to-be-Done (JTBD) Headline Framework

Headlines must state the **exact tangible outcome** and the **time or pain saved**.

### Formula:
`[Verb / Action] + [Target Asset / Data] + [Tools Used] + [Result / Time Saved]`

* ❌ **Bad (AI Slop):** *"Revolutionize your business efficiency with cutting-edge automated agentic intelligence."*
* ✅ **Good (JTBD):** *"Auto-Extract Invoices from Gmail into Google Sheets & Slack (Cuts 3 Hours/Week)."*

* ❌ **Bad (AI Slop):** *"Delve into our comprehensive directory of AI-powered creative applications."*
* ✅ **Good (JTBD):** *"Browse 150+ Tested AI Tools with Real Pricing, Free Tiers & Verified Video Demos."*

---

## 3. The "Can I Do This for Free?" Honesty Principle

SnapStack is built on user trust. On every tool review, workflow recipe, and skill guide:
1. Always state whether the task can be completed using a **free prompt in standard ChatGPT / Claude / Gemini** before pitching paid software or subscriptions.
2. Provide the direct prompt snippet:
   ```markdown
   > **Can I do this in ChatGPT for free?**
   > Yes. Copy the system prompt below into the free tier of ChatGPT (GPT-4o mini) or Claude 3.5 Sonnet to extract receipt line items without paying for specialized receipt parsers.
   ```

---

## 4. Action-Oriented Microcopy & Button CTAs

Buttons must state **exactly what will happen** upon clicking. Include testing dates and versions where applicable:

* ❌ *"Submit"* ➔ ✅ *"Submit Workflow for Review"*
* ❌ *"Click Here"* ➔ ✅ *"Copy System Prompt (Tested Nov 2026)"*
* ❌ *"Get Started"* ➔ ✅ *"Download Make.com Blueprint (.json)"*
* ❌ *"Learn More"* ➔ ✅ *"Watch 60s Video Breakdown"*
* ❌ *"Save"* ➔ ✅ *"Save to My Vault"*
